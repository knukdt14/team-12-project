# 정비소 선택 기준

## 공식 서비스센터 vs 사설 공업사
- 공식 서비스센터(브랜드 직영/협력점): 순정 부품 사용이 보장되고, 보증 수리 연계가 편리합니다. 대신 공임 단가가 사설 공업사보다 높은 편입니다.
- 사설 공업사: 비용이 상대적으로 저렴하고 예약 없이 빠르게 진행할 수 있는 경우가 많습니다. 부품 품질(순정/OEM/애프터마켓)은 업체별로 확인이 필요합니다.

## 판금·도색 전문 vs 종합 정비소
판금·도색은 전문 기술과 도장 부스 같은 별도 설비가 필요한 작업입니다. 종합 정비소보다 판금·도색 전문 업체(카센터/보디샵)를 이용하면 색상 매칭 품질이 더 좋은 경우가 많습니다.

## 견적 비교 시 확인할 점
- 부품 등급: 순정 부품 / OEM(호환) 부품 / 재생 부품 중 어떤 것을 쓰는지
- 도색 범위: 부분 도색인지 전체 도색인지
- 보증 기간: 도색·판금 작업에 대한 하자 보증 기간
- 수리 방식이 견적서에 구체적으로 명시되어 있는지 (예: "판금+도색"처럼 뭉뚱그리지 않고 세부 공정이 나와있는지)

## 정밀 견적이 필요한 경우
겉보기로는 경미해 보여도 내부 구조물(범퍼빔, 프레임 등)까지 손상됐을 가능성이 있는 충돌 사고는 사진만으로 정확한 견적을 내기 어렵습니다. 이런 경우 반드시 정비소를 방문해 직접 점검받는 것을 권장합니다.
